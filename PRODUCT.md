# Список сотрудников

<!-- impeccable:product-schema 1 -->

## Platform
web

## Stack
React + TypeScript and ordinary CSS; Node.js + Express + TypeScript; SQLite. Required by the supplied assignment. Deployment to Vercel is requested. Implementation choices are delegated by the user.

## Users
Assignment evaluators and registered users viewing an employee directory.

## Product Purpose
Register, sign in, find colleagues by name or department, and add employees. Persist accounts and employees across server restarts.

## Capabilities and Constraints
Employee full name, position and department are mandatory. Both the interface and employee API require authentication. Store password hashes. Provide five complete fictional demo employees with actual portrait assets. No full dashboard, email confirmation, or password recovery. Deliver source code and a concise README; postpone a separate report until the user reviews the app.

## Brand Commitments
Use the supplied screenshot as mood reference: near-black ground, charcoal panels, generous rounded shapes, light sans-serif typography, blue and pink accents. The reference is not a request to copy dashboard features. Russian interface, inferred from the assignment and user conversation.

## Evidence on Hand
Assignment DOCX supplied by user and reference screenshot. Employee identities and contact information will be clearly identified as demonstration content.

## Product Principles
Keep the directory focused. Make authentication, adding and filtering clear. Preserve the required stack. Prefer local startup without additional services and persistent Vercel deployment with minimal infrastructure.
